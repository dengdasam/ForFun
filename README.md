# for-fun · 广西来宾生态种植手册库

> 一套围绕 **广西来宾气候（年均温 20.7°C / 无霜期 331 天 / 年降水 1360mm / 红壤偏酸）** 本地化编写的种植手册集合。
> 全部为单文件 HTML，浅底深字（无白字阅读问题），可直接浏览器打开，已按来宾气候适配。

---

## 📍 适配背景（所有手册共用）

**来宾气候常量**
- 年均温 **20.7°C** ｜ 1 月均温 10.9°C ｜ 7 月均温 28.6°C ｜ 极端高温 38.9°C
- 无霜期 **331 天**（≈ USDA Zone 9+）｜ 年降水 1360mm（4–8 月占 70%）｜ 日照 1580–1660h
- 土壤：**红壤偏酸黏重**

**红壤铁律（定植前必做）**
1. 调酸（生石灰）
2. 接根瘤菌剂
3. 绿肥养地（翻压）
4. 翻压后隔 **2–3 周** 再定植
5. 菜园三件套：**避雨棚 + 遮阳网 + 高垄排水**（7–8 月 35°C+ 必须拉遮阳网，否则落花减产）
6. 黑水虻虫沙偏碱含钙，补红壤缺素、助番茄防脐腐
