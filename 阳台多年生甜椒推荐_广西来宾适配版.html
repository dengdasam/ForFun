先说一句最关键的：甜椒能"多年生"，但比辣椒（尤其是哈瓦那系）难。多篇家庭实操文献明确警告——大果厚皮甜椒天生一年生，强行做老桩，第 2 年长势会垮、果个缩水，多数人每 1–2 年重新育苗更划算。所以本手册的"多年生"定位是：以每年重新育苗为主、剪枝换头/老桩续命为辅，而来宾的气候让"续命"比北方容易得多（详见第三章）。

一、甜椒多年生 vs 辣椒多年生：本质难度差

你之前那本《不辣微辣辣椒总览》里，哈巴纳达、Roulette 这类 C. chinense 是"天生多年生"——3–5 年 vigor 衰减慢，几乎放着就活。甜椒路线完全是另一回事：

维度哈瓦那系（*C. chinense*）甜椒（*C. annuum* 灯笼型）
多年生类型天生多年生管理型多年生（靠技术续命）
难度几乎"放着就活"，3–5 年衰减慢需主动剪枝换头，第 2–3 年 vigor 明显递减
留种多可留种（开放授粉）多为 F1 杂交，不可留种，每年购种
大果代价果中等，植株负担小单果 170–500g，老株"挂果累趴"、第 2 年果缩
诚实结论：想要"真正省心的多年生 + 零辣风味"，那是哈瓦那系（哈巴纳达等）的活；甜椒路线的价值在于冲产量、补"做菜甜脆主角"这个档位，多年生只是锦上添花，别指望一棵老桩无限高产。

二、来宾气候：甜椒多年生的"天选之地"

✅ 来宾的两大天然优势

  • 331 天无霜期 + 年均 20.7°C：北方要搬屋、要保温棚才能越冬的甜椒，在来宾基本露天或避雨棚就能过冬，1 月均温 10.9°C，不用搬室内。
  • 冬季温和 = 老桩越冬零成本：多数地区越冬要"棉袄 + 小温室 + 控水"，来宾只需剪老枝、控水停肥、放避冻处即可，开春直接复剪换土续产。

⚠️ 唯一的命门：盛夏高温

  • 7 月均温 28.6°C、极端 38.9°C：甜椒 35°C 以上落花落果，这是来宾种甜椒的头号减产因素。
  • 必须复用你生态方案里的"避雨棚 + 遮阳网 + 高垄"三件套，否则再高产的种也发挥不出。
  • 红壤按铁律：调酸（生石灰）+ 接根瘤菌 + 绿肥养地 + 翻压后隔 2–3 周定植。
一句话定位：来宾种甜椒，"冬天不用管、夏天要遮阳"——和北方"夏天随便长、冬天拼命保"正好反过来。你的难点在盛夏，不在越冬。

四、T1 阳台多年生首选（紧凑 + 抗病 + 抗逆）

红英达

先正达引进杂交一代，灯笼形转红色，单果 170g。最大卖点是抗 5 种病 + 耐低温——这正是来宾高温高湿 + 想多年生最需要的"皮实基因"。株高仅 60–70cm，一盆一株刚好。若只先种一棵甜椒，选它最稳。

粤椒 1 号

华南（含广西）主栽的耐热耐湿绿甜椒，文献称"华南越冬型，12–2 月低温期单果重稳定"。等于在来宾气候下被验证过的本地化种，盛夏比北方种更扛得住。果肉厚、宜夏秋种植。

中椒 115

甜椒类杂交一代，单果 200–300g、连续坐果能力突出，南北皆宜、露地大棚都行。产量稳、易种，是"不想挑太细"时的安全牌。多年生靠剪枝换头续 2 年。

五、T2 大果高产型（需剪枝换头 / 设施）

太空椒（水果甜椒）

甜椒里的产量天花板——单果 300–500g，智能温室 + 吊蔓立体 + 水肥一体化下亩产最高 1 万斤（≈5000 kg）。但它是无限生长大果型，普通阳台/避雨棚会低一截，且老株第 2 年衰退明显，必须靠"剪枝换头/再生栽培"技术续产。适合有避雨棚 + 愿投入管理的你。

黄欧宝 / 紫星 / 橙彩椒

彩椒家族：黄欧宝黄果肥厚（高端市场）、紫星紫果小（观赏性强、最适合盆栽）、橙彩椒转色均匀鲜食。产量与红英达同档（4000 kg 级），多年生潜力中等。紫星是你阳台"好看又能吃"的优选。

六、T3 迷你 / 观赏甜椒（无需支架 · 最宜盆）

迷你甜椒 / 矮生彩椒

株高仅 40–50cm、不用搭架，单株挂果 10–15 个，从播种到采收约 90 天。文献称"阳台盆栽首选"——新手零失败、不占空间。虽单果小，但数量多、采摘期长，多年生靠老桩越冬最易操作。

Striped Holland（条纹荷兰）

国外 patio 专用彩椒，株高约 60cm，黄底红条纹像笔刷，甜脆适合鲜食/沙拉/酿馅。文献明确标注"high yielding、perfect for patio container"。国内需引种，是阳台"颜值 + 产量"兼顾的进阶选。

七、多年生管理技术（来宾版：冬天不用搬屋）

核心逻辑：甜椒多年生 = 剪枝换头 / 再生栽培 + 老桩越冬，但来宾冬季温和，越冬环节被大幅简化：
  1. 秋末修剪（关键）：气温稳过 10°C 时，剪除老枝、留 15–20cm 高茬，剪口抹草木灰/多菌灵抑菌，选留 3–4 个壮侧芽。
  2. 越冬（来宾超简单）：控水停肥、放避冻通风处即可——不用搬室内、不用保温棚（北方要做的"棉袄 + 小温室"，你基本省了）。严禁冬季施肥（冒新梢会被低温冻死 + 烂根）。
  3. 开春复剪：气温稳 15°C 以上，重剪枯病枝、换土、渐增光照、水肥跟进，约 1 个月重新开花结果。
  4. 剪枝换头（河北农科院技术）：收完果后从四门斗以上全打掉、叶片全摘，促腋芽重生，可连收 2–3 年（亩节本 + 增收）。
两条硬警告（来自老桩实操）：
  • "大果甜椒强行多年老桩，长势一年不如一年"——3–4 年后主干老化、结果力骤降，必须重新育苗更新，别指望一棵老桩无限高产。
  • 越冬严禁施肥——肥料刺激冒新梢，低温下直接冻死、还烂根。

九、与《辣椒总览》的路线地图

两条路线在你菜园里并存，互补不冲突

  • 甜椒路线（红英达 / 太空椒 / 迷你甜椒）＝产量天花板高（亩产 3000–5000 kg vs 哈巴纳达单株 3–5 kg），做菜甜脆主角，但靠技术续命、3–4 年更新。
  • 哈瓦那系（哈巴纳达 / Roulette 等）＝天生多年生省心、零辣风味好，但产量中等。
  • 实操建议：甜椒冲产量 + 当季鲜食；哈瓦那保风味和多年省心。两路阳台并存，正好覆盖"甜脆做菜档 + 零辣风味档"。

十、新手组合推荐

直接照着买

  • 组合 A（零门槛国内购）：红英达 + 迷你甜椒 + 中椒 115 → 彩椒红 / 迷你盆摘 / 大果甜椒三档全覆盖，全国内可买，多年生都靠剪枝换头。
  • 组合 B（华南本地化）：粤椒 1 号 + 紫星彩椒 → 专为华南耐热 + 盆栽观赏，来宾气候完美契合。
  • 组合 C（高产挑战）：太空椒（避雨棚 + 剪枝换头）→ 冲亩产天花板，适合已有设施管理基础。

十一、获取渠道现实

  • 国内易买：红英达、中椒 115、太空椒、粤椒 1 号、黄欧宝/紫星/橙彩椒、迷你甜椒/矮生彩椒（种子商城、农资店、淘宝均有）。
  • 需引种：Striped Holland 等国外 patio 彩椒（海淘/进口）。
  • 注意：甜椒多为 F1 杂交，不可留种，每年需购新种——这是和哈瓦那系（可留种）最大的长期成本差。
